# Experiment artifacts

`qfnn_experiments/` is the complete unpacked output directory generated by `src/qfnn_experiment_pipeline.py`. It has not been reduced to only the headline numbers.

## Map of the archive

- `run_config.json` records the complete command-line configuration, environment provenance, architecture choices, and data-selection protocol.
- `selected_recipes.json` and `selected_recipes.md` record the validation-selected recipe for each dataset.
- `studies/` contains the three SQLite Optuna studies. Each database contains 60 completed trials.
- `search/<dataset>/` contains every trial configuration, both search-seed runs, intermediate histories, and validation summaries.
- `final/<dataset>/` contains six final seeds (41–46), validation-selected checkpoints, training histories, and exact plus finite-shot test evaluations.
- `reports/` contains aggregate CSV, JSON, and Markdown summaries, the per-epoch mean/standard-deviation curves, and the rendered PNG/PDF figures.

The three studies evaluate MNIST8, FashionMNIST8, and KMNIST8 independently. Every trial trains for 30 epochs under search seeds 101 and 102. The chosen recipe for each dataset is then retrained for 100 epochs under six independent final seeds.

Some JSON files contain the original absolute output-directory strings from the machine on which the experiments were run. They are inert provenance fields; the archive remains readable and the code accepts a new `--outdir` on any machine.

The `.pt` checkpoints are PyTorch serialization files. As with any pickle-based artifact, load only the files from a trusted repository commit and do not load modified or untrusted checkpoints.
